Feasibility check

A robot that reads your want-to-read list and tells you when the price drops.

You asked whether a paid Claude or Cowork plan can do this. Short answer: yes. Longer answer: the AI part is the easy part, and there is a shortcut you should try first.

✓ Doable this weekend, no code required

“I want to create an AI process or agent of some sort where I can import my want-to-read list from Goodreads and it will comb the internet for book deals and alert me at some given frequency if there is a significant deal on one of my books. Do you think that is doable with a paid version of Cowork or Claude?”

— Christina, by email
The shape of the thing

Four moving parts, only one of them needs AI

Every version of this project, from the 20-minute one to the over-engineered one, is the same four-step loop. Getting the list out of Goodreads is a manual export. Checking prices is web lookups. Deciding what counts as “significant” is a rule you write once. Sending an alert is email. The AI earns its keep in step two and three: reading a messy spreadsheet, hunting across several stores, and judging whether a deal is actually good.

One wrinkle you can't design around: Goodreads shut down its public API in 2020, so nothing can “connect” to your account. The export button is the only door, and it is a manual one. That is fine, because a want-to-read list changes slowly.

Three sizes

Pick the smallest one that makes you happy

Start at the left. Move right only if the previous size annoys you.

1

The no-AI shortcut

20 minutes · free · try this first

Two services already do most of what you described, minus the Goodreads import.

  • BookBub has a Wishlist. Search a title, click “Save to Wishlist,” and it emails you when that book is discounted.
  • eReaderIQ watches Kindle prices for books you add and emails you when the price drops below a number you set.
  • Your library's Libby app is the ultimate “deal.” Most want-to-read books are free there, with a wait.
The catch: you add books one at a time by hand, and neither service reads your Goodreads list. For a list under 40 books, that is an evening with a glass of wine, not a project.
2 What I'd build

A Cowork scheduled task

An afternoon · Claude Pro or Max · no code

This is exactly what you asked for. Cowork, in the Claude desktop app, can save a task and run it on a schedule in the cloud, even with your laptop closed. It can search the web and use connected tools like Gmail and Google Drive.

  • Export your Goodreads library once, drop the CSV in Google Drive.
  • Write one prompt that says what to check, what counts as a deal, and to email you.
  • Set it to weekly. Re-export the CSV whenever your list changes.
The catch: usage limits. Each run spends part of your plan's allowance, and checking 300 books is a lot of web lookups. Keep a “priority” shelf of 25 to 50 titles, or let it work through the list in batches.
3

A real little program

A weekend · a developer friend · overkill

Have Claude Code write a small script that reads the CSV, checks prices on a schedule from a cloud server, keeps a price history, and emails a digest. Precise, cheap per run, and fully yours.

  • Price history means it can spot “lowest ever,” not just “on sale today.”
  • Runs on a fixed schedule with no plan limits to think about.
  • Needs someone to host it and fix it when a store changes its website.
The catch: maintenance. Stores redesign pages and block scrapers. Only worth it if size 2 leaves you wanting more, or if you enjoy the tinkering for its own sake.

Size 2, step by step

Setting up the Cowork version

Export your Goodreads library

On the desktop website (not the app): My Books → Import and export → Export Library. You get a CSV of every shelf. The column Exclusive Shelf says to-read for your want-to-read books. Goodreads only lets you export every few days, which is fine.

Put the file where the cloud can see it

Save it to a folder in Google Drive and connect Google Drive and Gmail in Claude's settings. Scheduled tasks run remotely, so they can't read a folder on your laptop, but they can read Drive.

Decide what “significant” means, in numbers

Vague rules make chatty robots. Something like: at least 50% off list, or $2.99 or less, or free, or available on Libby with no wait. Write the rule down before you write the prompt.

Create the scheduled task

In the Claude desktop app, open Cowork, start a new scheduled task, paste a prompt like the one below, and set the cadence to weekly. Run it once by hand first and read the result critically. Tighten the prompt until the email is something you'd actually want.

Keep the list small and fresh

Either add a shelf in Goodreads called something like deal-watch for the 25 to 50 books you'd buy tomorrow, or tell the task to check only a batch each week. Re-export when the list changes.

Starter prompt · edit freelyYou are my book-deal scout. Every run, do the following. 1. Open the newest file named goodreads_library_export*.csv in my Google Drive folder “Book deals”. 2. Keep only rows where Exclusive Shelf is “to-read”. If a row has a bookshelf tag “deal-watch”, treat those as the priority list; otherwise use the whole to-read list. 3. For each priority book, check the current price on Amazon Kindle, and check BookBub, Chirp (audiobooks), and Kobo for a current deal. Note the list price if you can find it. 4. A deal is SIGNIFICANT if any of these is true: a) at least 50% below list price, b) $2.99 or less, c) free, d) an audiobook under $5. 5. Email me at [my address] with subject “Book deals, week of [date]”. List only the significant deals: title, author, format, price now, list price, store, and a link. One line per book, best deal first. 6. If there are no significant deals, send one sentence saying so and how many books you checked. 7. Never guess a price. If you can't verify it, leave the book out and say how many you skipped.
Honest fine print

Where it will disappoint you, and what to do about it

✦Prices are checked, not guaranteed

AI reads web pages and web pages lie, cache, and vary by region. Treat the email as a tip, click through, and confirm before buying. The prompt's rule 7 is there so it says “I don't know” rather than inventing a number.

✦Amazon is not fond of robots

Direct Amazon lookups sometimes get blocked or return stale pages. Deal aggregators like BookBub and eReaderIQ are easier for an agent to read reliably, which is why the prompt checks them too.

✦Usage limits are the real ceiling

Paid plans meter how much Claude you use. A weekly run over 40 books is comfortable. A daily run over 400 will run out of allowance, and you'll get a polite failure instead of an email. Weekly, small list, priority shelf.

✦Alerts need a delivery route

Cowork puts results on its Scheduled tasks page. To get pinged, connect Gmail and tell it to email you, as the prompt does. Without that step you'd have to remember to go look, which defeats the purpose.

My recommendation

Spend twenty minutes on BookBub's wishlist tonight with your top ten books. If that scratches the itch, you're done and you paid nothing. If you find yourself wanting the whole list watched, the Cowork scheduled task is a real, working answer on a Pro plan, and the prompt above is most of the work. Skip size 3 unless it sounds fun.
